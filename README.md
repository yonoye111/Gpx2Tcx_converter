# Gpx2Tcx_converter
Gpx to Tcx file converter

I want to introduce my favorite site gpx.studio.
I want to convert the output gpx file from gpx.stucio 
to tcx file with converting the rich waypoints edited 
by gpx.studio.

Usage:
1. Run yGpx2Tcx2.py first in VSCode.
2. Select gpx.studio output gpx file.
3. Run Code_for_Validation3.py to check if the 2. output tcx file is correct.

or Run:

!python yGpx2Tcx2.py Porksaute.gpx tmp.tcx
